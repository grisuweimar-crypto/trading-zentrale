# QM-B Project Restrictions

This package evaluates only **internal scanner/research policy**. It deliberately does not evaluate legal eligibility, broker availability, exchange listing or market tradability.

The current v1 policy allows the asset types already supported by prospective membership (`stock`, `etf`, `fund`) and has no explicit internal blocked or restricted instrument IDs.

A `CLEAR` result therefore means only: the instrument is not blocked by the current project policy. It must not be interpreted as listed, tradable, executable, legally eligible or investable.

Policy evidence becomes valid no earlier than the actual observation time of the policy version. It is never back-projected to the earlier membership timestamp.

The current durable membership snapshot contains 207 stable instrument claims. Under the current internal policy, all 207 are expected to be `CLEAR` prospectively from the policy observation time onward.
