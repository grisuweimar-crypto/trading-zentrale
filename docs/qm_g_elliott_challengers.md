# QM-G / BA-QM6 – Elliott Challenger Registry

QM-G keeps the existing Elliott-vNext implementation frozen as the research core. New Elliott ideas are not added to the hard-rule engine. They enter only as versioned, research-only sidecar challengers.

## Mandatory challenger bindings

Every challenger version binds to:

- one QM-C hypothesis/version and family;
- one QM-C analysis-plan version;
- one frozen QM-C multiplicity control plan;
- one QM-A analysis/version and its current evidence state;
- an explicit feature definition;
- a PIT contract that forbids future data and retroactive reclassification;
- a frozen Elliott count/scenario identity created before outcome inspection;
- a frozen Elliott core identity;
- QM-I lineage references for core and challenger;
- the existing QM-F stateful B5-vs-B6 incremental ablation contract for Decision-Layer value.

The example challenger ideas listed in the QM Masterplan are documented in the config, but are **not** activated as rules merely by being named there.

## Hard boundaries

QM-G does not:

- change Elliott hard rules or make a historical count fit after seeing outcomes;
- replace W6 or infer direction from Elliott into Universal Stance;
- replace the W8 action matrix;
- create Portfolio Actions directly;
- create orders or enable execution;
- perform productive promotion.

Shared ancestry between core and challenger is expected to be visible to QM-I. It must never be presented as independent confirmation. Common/direct ancestry triggers review, but is not by itself declared a defect.

## Promotion semantics

A challenger registry entry is not evidence of usefulness. Confirmatory evaluation remains bound to QM-C/QM-A/QM-I and preserves QM-B fail-closed universe/investability constraints through the existing QM-C2 confirmation-readiness gate. If the challenger is evaluated for Portfolio Action impact, the existing QM-F B5/B6 contract is authoritative: same starting state, observation grid, eligibility, tradeability, action availability and costs; only the registered Elliott adjustment may differ. A later promotion would require separately demonstrated incremental benefit and a separate promotion decision.
